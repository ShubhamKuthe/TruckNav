# TruckNav Mobile

TruckNav Mobile is the Android Flutter companion app for the TruckNav Connector.

Phase 1 currently provides:

- custom TruckNav-themed application shell
- discovery screen with Connector selection flow
- connector detail / game selection screen
- fullscreen GPS shell with 3-second auto-hide controls
- settings shell driven by central session state

The approved `design-reference/trucknav-mobile.html` file is not present in the repository yet, so this UI is structured and themed for the product but should not be treated as final visual implementation.
